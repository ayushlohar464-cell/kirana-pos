# 🛒 KiranaPOS & Wireless Mobile Barcode Scanner

Smart, Offline-First Kirana Store Management & POS System with Wireless Mobile Barcode Scanner.

## 🚀 Features
- ⚡ **Ultra-Fast Barcode Scanner**: Hardware GPU-accelerated scanning with continuous auto-focus, flashlight torch, and instant detection.
- 📱 **Mobile POS & Billing**: Direct mobile billing for shop owners on the go.
- 🛒 **Real-Time PC & Mobile Sync**: Live Server-Sent Events (SSE) synchronization between cashier counter and floor staff.
- 🧾 **Thermal Receipt Generation**: Formatted receipt with one-click WhatsApp sharing and thermal printing.
- 🌐 **Free Cloud Hosting Ready**: Works on Render, Koyeb, Railway, or local offline LAN.

## 🛠️ Quick Start
```bash
npm install
npm start
```
- Web POS: `http://localhost:3000`
- Mobile Scanner: `http://<your-ip>:3000/scanner.html`
